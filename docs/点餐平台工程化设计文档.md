## 0. 文档说明

本文档将需求 v1.2 转化为可执行的工程方案，覆盖：工程结构与技术版本、后端设计（模块/鉴权/支付/退款/定时任务）、**17 张表完整建表 SQL**、前端双端工程、部署编排（docker-compose/Nginx/CI-CD）、开发排期与工程规范。

**本文采用的默认决策**（对应需求 §18 推荐值，拍板后如有变更仅影响局部）：

| 决策 | 本档采用 |
|---|---|
| 接单模式 | 手动接单（默认），店铺可开自动接单；未接单 10 分钟自动退款 |
| 超时参数 | 未支付 15 分钟关单；未接单 10 分钟自动退款；售后 24 小时 |
| 每日限量库存 | 表结构预留 `stock_quantity`，MVP 默认不启用扣减 |
| 图片存储 | 本地存储（Docker 卷）+ 压缩缩略图，`StorageService` 抽象 |
| 店员退款权限 | MVP 仅店主可审核/主动退款 |
| 后厨打印 | V1 接入（本档预留接口与表，不在 MVP 实现） |
| UI 组件库 | 骨架阶段用两端真机对比 NutUI-React / Taroify 后确定 |

## 2. 后端工程设计

### 2.1 工程结构（单 Maven 模块 + 领域分包）

MVP 单店、单体部署，采用**单模块 + 按领域分包**，避免过度工程；多店扩展只增加数据不改变结构。

```
server/src/main/java/com/example/ordering/
├── OrderingApplication.java
├── common/                # Result<T>、ErrorCode、BusinessException、PageResult、工具类
├── config/                # SecurityConfig、JwtConfig、MybatisPlusConfig、ScheduleConfig、CorsConfig
├── security/              # JwtService、JwtAuthFilter、Audience 校验、LoginUser
├── tenant/                # StoreTenantLineHandler（MyBatis-Plus 多租户插件）
├── module/
│   ├── auth/              # 顾客静默登录（weapp/alipay）、员工登录/刷新
│   ├── store/             # 店铺信息与业务参数
│   ├── menu/              # 分类、菜品、规格组/项、加料组/项
│   ├── table/             # 桌台、桌码解析、重置

│   ├── payment/           # PayService 抽象 + 微信/支付宝实现 + 回调 Controller

```

### 2.2 核心类设计

| 类 | 职责要点 |
|---|---|
| `JwtService` | 签发/校验 access(2h) + refresh(14d)；`aud` 区分 customer/merchant；merchant 校验 `staff.token_version` 与状态 |
| `JwtAuthFilter` | 解析 token → 注入 `LoginUser`；按 URL 前缀（`/api/v1/c`、`/api/v1/m`）校验 audience |
| `StoreTenantLineHandler` | 多租户插件：所有业务表自动追加 `store_id = ?`；`orders`/`refund` 按当前员工所属门店注入 |
| `PayService` | `createPayment` / `queryPayment` / `closeOrder` / `refund` / `queryRefund` / `verifyNotify` |
| `WechatPayServiceImpl` | JSAPI 下单（需 openid）、APIv3 验签解密、微信退款通知 |
| `AlipayPayServiceImpl` | `alipay.trade.create`（需用户 ID）、`my.tradePay` 参数、退款查询 |
| `OrderService` | 创建（价格重算 + 校验 + 幂等）、发起支付、履约流转（条件更新） |
| `RefundService` | 场景矩阵分发、可退余额校验、订单行锁、退款单状态机、结果回写 |
| `TaskScheduler` | @Scheduled 定时任务（见 2.6） |

### 2.3 认证与鉴权链路

- **顾客**：小程序 `Taro.login()` / `my.getAuthCode()` → `POST /api/v1/c/auth/login` → 后端换 openid → 查/建 `customer` → 签发 customer JWT。token 过期时前端静默重登，**不设 refresh**（需求 v1.2 §10.1）
- **员工**：`POST /api/v1/m/auth/login` → access + refresh；`token_version` 失效机制
- **拦截器顺序**：`JwtAuthFilter` → 租户上下文（store_id）→ 限流拦截器（下单/退款申请按 IP + customer 限流）→ Controller

### 2.4 统一响应与异常

- 响应体：`{ code, message, data }`；分页：`{ list, total, page, pageSize }`
- 全局 `@RestControllerAdvice` 统一捕获：`BusinessException`（按 ErrorCode 映射）、参数校验异常、兜底 500
- 错误码与需求 §11.1 一致，`ErrorCode` 枚举集中定义

### 2.5 多租户插件配置

```java
@Bean
public MybatisPlusInterceptor mybatisPlusInterceptor() {
    MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
    interceptor.addInnerInterceptor(new TenantLineInnerInterceptor(new StoreTenantLineHandler()));
    interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.POSTGRE_SQL));
    return interceptor;
}
```

- `TenantLineHandler` 返回当前登录员工可访问的 `store_id` 列表（店主可多店 → 用 IN 条件；MVP 单店 → 单值）
- 忽略表：`customer`、`customer_auth`、`staff`、`order_status_log` 中无需按店过滤的除外

### 2.6 定时任务清单（单实例 @Scheduled，MVP 不引入分布式锁）

| 任务 | 频率 | 逻辑 |
|---|---|---|
| 未支付关单 | 每 1 分钟 | `status=PENDING_PAY AND pay_expire_at < now()` → 置 CLOSED + 调渠道关单 + 写日志 |
| 未接单自动退款 | 每 1 分钟 | `status=PAID AND paid_at < now()-accept_timeout` → 自动取消 + 发起全额退款 |
| 支付结果补偿查单 | 每 5 分钟 | `status=PENDING_PAY` 超时未回调的 → 调渠道查单按真实结果更新；已关闭的迟到成功 → 自动全额退款 |
| 退款结果补偿 | 每 5 分钟 | `refund.status=PROCESSING` 超 N 分钟 → 渠道查询更新 |
| 待审核退款提醒 | 每 10 分钟 | `refund.status=APPLYING` 超 2 小时 → 再次提醒店主 |
| 对账提醒（V1） | 每日 | 生成前一日流水摘要 |

## 3. 数据库 DDL（17 张表，PostgreSQL 16）

> 约定：`id BIGSERIAL PRIMARY KEY`；`created_at/updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`；软删除表含 `deleted SMALLINT NOT NULL DEFAULT 0`（MyBatis-Plus `@TableLogic`）；金额均为 `BIGINT`（分）；**不建物理外键**（用索引 + 应用层校验，避免死锁、便于扩展）；状态字段用 `SMALLINT` 或 `VARCHAR` 枚举（下文按可读性用 VARCHAR，实际可折中为 SMALLINT + 枚举）。

```sql
-- ========== 1. store 门店与业务参数 ==========
CREATE TABLE store (
    id               BIGSERIAL PRIMARY KEY,
    name             VARCHAR(64)  NOT NULL,
    logo             VARCHAR(255),
    phone            VARCHAR(20),
    address          VARCHAR(255),
    business_status  SMALLINT     NOT NULL DEFAULT 1,  -- 1营业 0打烊
    business_hours   VARCHAR(64),
    auto_accept      BOOLEAN      NOT NULL DEFAULT FALSE,
    pay_timeout_min  INT          NOT NULL DEFAULT 15,
    accept_timeout_min INT        NOT NULL DEFAULT 10,
    after_sale_hours INT          NOT NULL DEFAULT 24,
    created_at       TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at       TIMESTAMPTZ  NOT NULL DEFAULT now()
);

-- ========== 2. customer 顾客 ==========
CREATE TABLE customer (
    id         BIGSERIAL PRIMARY KEY,
    nickname   VARCHAR(64),
    avatar     VARCHAR(255),
    phone      VARCHAR(20),          -- 预留，MVP 不采集
    status     SMALLINT    NOT NULL DEFAULT 1,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- ========== 3. customer_auth 顾客平台身份 ==========
CREATE TABLE customer_auth (
    id          BIGSERIAL PRIMARY KEY,
    customer_id BIGINT      NOT NULL,
    platform    VARCHAR(16) NOT NULL,            -- WECHAT / ALIPAY
    open_id     VARCHAR(64) NOT NULL,
    union_id    VARCHAR(64),
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uk_customer_auth UNIQUE (platform, open_id)
);
CREATE INDEX idx_customer_auth_cid ON customer_auth(customer_id);

-- ========== 4. staff 员工 ==========
CREATE TABLE staff (
    id            BIGSERIAL PRIMARY KEY,
    store_id      BIGINT       NOT NULL,
    username      VARCHAR(32)  NOT NULL,
    password_hash VARCHAR(100) NOT NULL,          -- BCrypt
    name          VARCHAR(32)  NOT NULL,
    role          VARCHAR(16)  NOT NULL DEFAULT 'STAFF',  -- OWNER / STAFF
    status        SMALLINT     NOT NULL DEFAULT 1,
    token_version INT          NOT NULL DEFAULT 0,        -- 停用/改密 +1 使旧 token 失效
    created_at    TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at    TIMESTAMPTZ  NOT NULL DEFAULT now(),
    CONSTRAINT uk_staff_username UNIQUE (username)
);
CREATE INDEX idx_staff_store ON staff(store_id);

-- ========== 5. category 分类 ==========
CREATE TABLE category (
    id         BIGSERIAL PRIMARY KEY,
    store_id   BIGINT      NOT NULL,
    name       VARCHAR(32) NOT NULL,
    sort       INT         NOT NULL DEFAULT 0,
    status     SMALLINT    NOT NULL DEFAULT 1,
    deleted    SMALLINT    NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_category_store ON category(store_id);

-- ========== 6. dish 菜品 ==========
CREATE TABLE dish (
    id             BIGSERIAL PRIMARY KEY,
    store_id       BIGINT       NOT NULL,
    category_id    BIGINT       NOT NULL,
    name           VARCHAR(64)  NOT NULL,
    description    VARCHAR(255),
    price          BIGINT       NOT NULL,         -- 基础价（分）
    image          VARCHAR(255),
    sort           INT          NOT NULL DEFAULT 0,
    status         SMALLINT     NOT NULL DEFAULT 1,   -- 1上架 0下架
    is_sold_out    BOOLEAN      NOT NULL DEFAULT FALSE,
    stock_quantity INT,                            -- 空 = 不限量（MVP 默认不启用）
    deleted        SMALLINT     NOT NULL DEFAULT 0,
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT now()
);
CREATE INDEX idx_dish_store_cat ON dish(store_id, category_id);

-- ========== 7. dish_spec_group 规格组 ==========
CREATE TABLE dish_spec_group (
    id         BIGSERIAL PRIMARY KEY,
    dish_id    BIGINT      NOT NULL,
    name       VARCHAR(32) NOT NULL,
    required   BOOLEAN     NOT NULL DEFAULT TRUE,
    sort       INT         NOT NULL DEFAULT 0,
    deleted    SMALLINT    NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_spec_group_dish ON dish_spec_group(dish_id);

-- ========== 8. dish_spec_item 规格项 ==========
CREATE TABLE dish_spec_item (
    id          BIGSERIAL PRIMARY KEY,
    group_id    BIGINT      NOT NULL,
    name        VARCHAR(32) NOT NULL,
    price_delta BIGINT      NOT NULL DEFAULT 0,   -- 加价（分），可为负
    is_default  BOOLEAN     NOT NULL DEFAULT FALSE,
    sort        INT         NOT NULL DEFAULT 0,
    deleted     SMALLINT    NOT NULL DEFAULT 0,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_spec_item_group ON dish_spec_item(group_id);

-- ========== 9. addon_group 加料组 ==========
CREATE TABLE addon_group (
    id         BIGSERIAL PRIMARY KEY,
    dish_id    BIGINT      NOT NULL,
    name       VARCHAR(32) NOT NULL,
    max_count  INT         NOT NULL DEFAULT 1,    -- 组内最多可选数
    sort       INT         NOT NULL DEFAULT 0,
    deleted    SMALLINT    NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_addon_group_dish ON addon_group(dish_id);

-- ========== 10. addon_item 加料项 ==========
CREATE TABLE addon_item (
    id          BIGSERIAL PRIMARY KEY,
    group_id    BIGINT      NOT NULL,
    name        VARCHAR(32) NOT NULL,
    price_delta BIGINT      NOT NULL DEFAULT 0,
    sort        INT         NOT NULL DEFAULT 0,
    deleted     SMALLINT    NOT NULL DEFAULT 0,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_addon_item_group ON addon_item(group_id);

-- ========== 11. dining_table 桌台 ==========
CREATE TABLE dining_table (
    id         BIGSERIAL PRIMARY KEY,
    store_id   BIGINT      NOT NULL,
    code       VARCHAR(16) NOT NULL,              -- 桌号（展示）
    qr_token   VARCHAR(64) NOT NULL,              -- 随机不可猜，唯一
    status     SMALLINT    NOT NULL DEFAULT 1,    -- 1可用 0停用
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uk_table_qr_token UNIQUE (qr_token),
    CONSTRAINT uk_table_store_code UNIQUE (store_id, code)
);

-- ========== 12. orders 订单主表 ==========
CREATE TABLE orders (
    id               BIGSERIAL PRIMARY KEY,
    order_no         VARCHAR(32)  NOT NULL,       -- 规则见下
    client_request_id VARCHAR(64) NOT NULL,       -- 客户端请求ID，防重复下单
    store_id         BIGINT       NOT NULL,
    table_id         BIGINT,                      -- 外带/自提扩展时可空
    customer_id      BIGINT       NOT NULL,
    platform         VARCHAR(16)  NOT NULL,       -- WECHAT / ALIPAY
    status           VARCHAR(16)  NOT NULL,       -- PENDING_PAY/PAID/MAKING/READY/DONE/CLOSED/CANCELLED
    refund_status    VARCHAR(16)  NOT NULL DEFAULT 'NONE',  -- NONE/PARTIAL/FULL
    total_amount     BIGINT       NOT NULL,       -- 应付总额（分）
    pay_amount       BIGINT       NOT NULL,       -- 实付（分）
    refunded_amount  BIGINT       NOT NULL DEFAULT 0,
    people_count     INT          NOT NULL DEFAULT 1,
    remark           VARCHAR(255),
    pay_expire_at    TIMESTAMPTZ  NOT NULL,
    paid_at          TIMESTAMPTZ,
    accepted_at      TIMESTAMPTZ,
    ready_at         TIMESTAMPTZ,
    done_at          TIMESTAMPTZ,
    cancelled_at     TIMESTAMPTZ,
    cancel_reason    VARCHAR(255),
    version          INT          NOT NULL DEFAULT 0,   -- 乐观锁
    created_at       TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at       TIMESTAMPTZ  NOT NULL DEFAULT now(),
    CONSTRAINT uk_orders_order_no UNIQUE (order_no),
    CONSTRAINT uk_orders_client_req UNIQUE (customer_id, client_request_id)
);
CREATE INDEX idx_orders_store_status ON orders(store_id, status, created_at DESC);
CREATE INDEX idx_orders_customer ON orders(customer_id, created_at DESC);

-- ========== 13. order_item 订单明细（快照） ==========
CREATE TABLE order_item (
    id              BIGSERIAL PRIMARY KEY,
    order_id        BIGINT       NOT NULL,
    dish_id         BIGINT       NOT NULL,
    dish_name       VARCHAR(64)  NOT NULL,
    dish_image      VARCHAR(255),
    spec_item_ids   JSONB,                        -- 所选规格项ID数组（JacksonTypeHandler）
    addon_item_ids  JSONB,                        -- 所选加料项ID数组
    spec_desc       VARCHAR(128),                 -- 如 "大杯"（展示快照）
    addon_desc      VARCHAR(255),                 -- 如 "珍珠+2, 椰果+2"
    unit_price      BIGINT       NOT NULL,        -- 单价（含规格/加料加价）
    quantity        INT          NOT NULL,
    total_price     BIGINT       NOT NULL,
    refunded_qty    INT          NOT NULL DEFAULT 0,
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT now()
);
CREATE INDEX idx_order_item_order ON order_item(order_id);

-- ========== 14. payment 支付记录（订单 1:N） ==========
CREATE TABLE payment (
    id               BIGSERIAL PRIMARY KEY,
    order_id         BIGINT      NOT NULL,
    out_trade_no     VARCHAR(32) NOT NULL,        -- 商户订单号 = 幂等键
    channel          VARCHAR(16) NOT NULL,        -- WECHAT / ALIPAY
    transaction_no   VARCHAR(64),                 -- 渠道交易号（回调后回填）
    amount           BIGINT      NOT NULL,
    status           VARCHAR(16) NOT NULL DEFAULT 'PENDING',  -- PENDING/SUCCESS/CLOSED
    paid_at          TIMESTAMPTZ,
    refunded_amount  BIGINT      NOT NULL DEFAULT 0,
    created_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at       TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT uk_payment_out_trade_no UNIQUE (out_trade_no),
    CONSTRAINT uk_payment_channel_txn UNIQUE (channel, transaction_no)  -- PG 允许多个 NULL
);
CREATE INDEX idx_payment_order ON payment(order_id);

-- ========== 15. refund 退款单 ==========
CREATE TABLE refund (
    id                BIGSERIAL PRIMARY KEY,
    refund_no         VARCHAR(32)  NOT NULL,      -- 商户退款单号 = 渠道幂等键
    order_id          BIGINT       NOT NULL,
    payment_id        BIGINT,
    type              VARCHAR(16)  NOT NULL,      -- FULL/ITEM/CUSTOM
    initiator         VARCHAR(16)  NOT NULL,      -- CUSTOMER/MERCHANT/SYSTEM
    amount            BIGINT       NOT NULL,
    reason            VARCHAR(255),
    reject_reason     VARCHAR(255),
    status            VARCHAR(16)  NOT NULL,      -- APPLYING/PROCESSING/SUCCESS/FAILED/REJECTED/WITHDRAWN/OFFLINE
    channel_refund_no VARCHAR(64),
    operator_id       BIGINT,                     -- 操作员工（系统发起为空）
    success_at        TIMESTAMPTZ,
    fail_reason       VARCHAR(255),
    version           INT          NOT NULL DEFAULT 0,
    created_at        TIMESTAMPTZ  NOT NULL DEFAULT now(),
    updated_at        TIMESTAMPTZ  NOT NULL DEFAULT now(),
    CONSTRAINT uk_refund_no UNIQUE (refund_no)
);
CREATE INDEX idx_refund_order ON refund(order_id);
CREATE INDEX idx_refund_status ON refund(status);

-- ========== 16. refund_item 退款明细（按菜品退） ==========
CREATE TABLE refund_item (
    id             BIGSERIAL PRIMARY KEY,
    refund_id      BIGINT NOT NULL,
    order_item_id  BIGINT NOT NULL,
    quantity       INT    NOT NULL,
    amount         BIGINT NOT NULL,
    created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_refund_item_refund ON refund_item(refund_id);

-- ========== 17. order_status_log 状态流转日志 ==========
CREATE TABLE order_status_log (
    id            BIGSERIAL PRIMARY KEY,
    order_id      BIGINT      NOT NULL,
    from_status   VARCHAR(16),
    to_status     VARCHAR(16) NOT NULL,
    operator_type VARCHAR(16),                    -- CUSTOMER/MERCHANT/SYSTEM/PAY_CHANNEL
    operator_id   BIGINT,
    remark        VARCHAR(255),
    created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_log_order ON order_status_log(order_id);
```

**编号规则**：
- `order_no`：`yyyyMMddHHmmss` + 4 位随机数字（唯一索引兜底，冲突重试一次）
- `refund_no`：`R` + `yyyyMMddHHmmss` + 4 位随机数字
- `out_trade_no`：直接复用 `order_no`

**数据初始化（init.sql 追加）**：默认店主账号（BCrypt 密码）、默认分类/菜品示例、桌台示例、店铺默认参数。

**双端差异封装（关键三处）**：

| 场景 | 微信（weapp） | 支付宝（alipay） |
|---|---|---|
| 静默登录 | `Taro.login()` → code → `POST /c/auth/login`（platform=WECHAT） | `my.getAuthCode({scopes:'auth_base'})` → authCode（platform=ALIPAY） |
| 扫码启动参数 | `query.q` 取桌码链接 URL | `query.qrCode` |
| 支付 | `Taro.requestPayment`（后端返回签名参数） | `my.tradePay`（后端返回 tradeNO/orderStr） |

- 请求封装：401 时静默重登后重放原请求；非 0 code 统一 Toast + 跳转
- 菜单接口结果按分类缓存；沽清状态以接口返回为准（不本地改价）
- 包体积控制：图片全部走服务端 URL，不本地打包；按需引入组件库

### 5.2 Nginx 配置要点（`deploy/nginx/conf.d/ordering.conf`）

```
server {
    listen 443 ssl http2;
    server_name ordering.example.com;

    # 商家端静态资源
    location / {
        root /usr/share/nginx/merchant;
        try_files $uri /index.html;
    }
    # API 反向代理
    location /api/ {
        proxy_pass http://backend:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    # 桌码落地页（普通浏览器扫码）
    location = /q/ {
        root /usr/share/nginx/html;
    }
    # 菜品图片静态
    location /uploads/ {
        alias /data/uploads/;
        expires 7d;
        add_header Cache-Control "public";
    }
    # 支付回调：超时放宽、禁止缓冲
    location /api/v1/pay/notify/ {
        proxy_read_timeout 60s;
        proxy_buffering off;
        proxy_pass http://backend:8080;
    }
    # WebSocket（V1 实时推送预留）
    location /ws/ {
        proxy_pass http://backend:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 3600s;
    }
}
```
